# Mostafa Yakout — Portfolio

A responsive, accessible portfolio for **Mostafa Yakout**, Software Engineer and Oracle APEX Developer.

**Live site:** [cv.rf.gd](https://cv.rf.gd)

## Built with

- Semantic HTML5
- Modern CSS with responsive editorial layouts and purposeful motion
- English and Arabic content with complete RTL support
- Vanilla JavaScript for navigation, language persistence, section tracking, counters, and progressive reveal effects
- No framework or build step

## Local preview

Open `index.html` directly, or serve the directory with any static web server. For example:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Structure

- `index.html` — page content and metadata
- `styles.css` — visual system and responsive design
- `script.js` — lightweight interaction layer
- `assets/` — portrait, CV, and certification documents
- `exam/cn/` — standalone computer networks exam tool from the original site
